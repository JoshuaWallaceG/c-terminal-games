# C Terminal Games
A collection of classic board games rebuilt in C, including Craps, Yahtzee, Battleship, and Hold’em Poker.

## Features
- Terminal-based gameplay
- Classic board, dice, and card game mechanics
- Player-vs-computer interactions
- Turn-based game flow and scoring systems

## How to Run
Build and run each project using your preferred C development environment.

## Technical Concepts
- 2D array-based board and deck representations
- Struct-based game state modeling
- Pointer-based state updates and pass-by-reference logic
- Input parsing, validation, and buffer management
- Randomized shuffling, dice rolling, placement, and AI decision logic

## Built With
- C
- Terminal / Console Application
